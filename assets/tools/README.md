# Tool icons

Drop an SVG here named after the tool, lowercased, spaces as hyphens:

    figma.svg  illustrator.svg  photoshop.svg  framer.svg

`build.py` picks them up automatically — no code change needed. Any tool
without a matching file falls back to a monogram in the site's own type.

These are trademarked brand marks, so they are not bundled. Get the official
files from each vendor's brand or press page, and follow their usage terms —
most permit showing the mark to indicate a tool you use, but require you not
to alter it. Downloading the real asset also avoids a hand-redrawn logo,
which looks worse than no logo at all.
