How I work

Product direction, interface craft, and an AI-assisted build practice.

  • A

    Interaction is the product

    What holds my attention is how a thing responds — what it does while it waits, and how it recovers. The happy path is the easy half.

  • B

    I build what I design

    A prototype in code answers questions a static frame cannot. This site is the proof: my Figma, my code, my tests.

  • C

    Trust has to be visible

    AI, blockchain and fintech all ask people to believe something they cannot check. The interface is where that belief is won or lost.
